# Stage 2：ER DSL → 可编辑 ER Canvas

## 目标

把 ER DSL 变成用户可以直接编辑的数据库设计图。

## 1. Canvas 架构

```text
ER DSL
  ↕
Canvas Adapter
  ↕
React Flow
```

不要让 React Flow JSON 成为 Source of Truth。

## 2. TableNode

显示：

```text
┌──────────────────────┐
│ users                │
├──────────────────────┤
│ PK id      BIGINT    │
│    username VARCHAR  │
│    email    VARCHAR  │
└──────────────────────┘
```

节点只负责显示与交互。

## 3. Edge

支持：

- 1:1
- 1:N
- N:M

显示 cardinality。

## 4. 必须实现

表：

- 新建
- 删除
- 重命名

字段：

- 新建
- 删除
- 修改
- 类型
- nullable
- PK
- unique

关系：

- 新建
- 删除
- cardinality

画布：

- 拖动
- 缩放
- 平移
- 自动布局
- fit view

## 5. 同步

结构变化：

```text
User Edit
 ↓
DSL Mutation
 ↓
Canvas Re-render
```

位置变化：

```text
Drag
 ↓
Update position in DSL
```

## 6. 导入导出

第一版：

```text
DSL JSON import/export
```

后续：

```text
SQL import/export
SVG/PNG export
```

SQL Parser 放后端。

## 7. AI 修改

Agent 不直接操作 React Flow。

```text
Agent
 ↓
DSL Mutation
 ↓
Backend
 ↓
SSE/WebSocket
 ↓
Canvas
```

例如：

```text
set_field_constraint(
  table="users",
  field="email",
  unique=true
)
```

## 8. 验收

用户可以：

1. 导入 DSL
2. 查看 ER
3. 拖动
4. 修改字段
5. 新增表
6. 建立关系
7. 导出
8. 重新导入

数据必须保持一致。
