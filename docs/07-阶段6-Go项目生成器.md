# Stage 6：Architecture DSL → Go 项目

## 目标

根据确认后的设计生成真正的 Go 项目骨架。

## 1. 原则

不要：

```text
LLM → 5000 行代码
```

而是：

```text
ER DSL
+
Architecture DSL
 ↓
Deterministic Generator
 ↓
Go Project
```

## 2. 目录

```text
project/
├── cmd/server/
├── internal/
│   ├── handler/
│   ├── service/
│   ├── repository/
│   ├── model/
│   ├── middleware/
│   ├── config/
│   └── router/
├── migrations/
├── pkg/
├── configs/
├── go.mod
└── README.md
```

## 3. Generator

拆成：

```text
ProjectGenerator
ModelGenerator
HandlerGenerator
ServiceGenerator
RepositoryGenerator
RouterGenerator
ConfigGenerator
MigrationGenerator
ReadmeGenerator
```

## 4. 顺序

```text
Project Metadata
 ↓
go.mod
 ↓
Model
 ↓
Repository
 ↓
Service
 ↓
Handler
 ↓
Router
 ↓
Config
 ↓
Main
```

## 5. 业务代码边界

第一版只生成：

- interface
- 基础方法
- TODO
- 必要依赖

不要编造复杂业务规则。

## 6. AI 的作用

AI：

- 推荐结构
- 修改 DSL
- 解释结果
- 根据错误提出修复

Generator：

- 创建文件
- package
- import
- struct
- interface
- router
- config

## 7. 验收

生成项目至少可以：

```bash
go mod tidy
go build ./...
```
